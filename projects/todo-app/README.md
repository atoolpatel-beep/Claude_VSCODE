# Todo App

A simple todo list built with plain HTML and CSS, plus a small JavaScript file for interactivity. No build step or dependencies.

## Features
- Add, complete and delete tasks
- Optional due date per task, highlighted when due today or overdue
- Filter: All / Active / Completed
- Clear all completed tasks
- Tasks are saved in the browser (`localStorage`)
- Light and dark mode follow the system setting

## Run
Open `index.html` in a browser:

```powershell
start projects/todo-app/index.html
```
